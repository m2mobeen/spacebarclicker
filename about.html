About Spacebar Clicker: Original Game by Bruno Croci, Version History & GitHub

Welcome to Spacebar Clicker! Many players ask us where this game came from, who is Bruno Croci, is there an official Spacebar Clicker 2, and where to find the GitHub source code. On this page, we share the whole story of this tiny game, give full credit to the original author, and explain our version updates.

The Original Game by Bruno Croci (CrociDB)

The original Spacebar Clicker was created by web developer Bruno Croci (known online as CrociDB, bruno.croci.me). He created this game as an entry for the famous js13kGames competition — an international programming challenge where developers must build a complete web game inside an absolute limit of only 13 kilobytes of code!

Because of this strict 13kb size limit, Bruno Croci did not use heavy game engines, images, or sound files. Instead, he made the game with pure HTML, CSS, and procedural 8-bit sound synthesized in real-time by jsfxr. He also came up with the funny original helpers that everyone loves: the confused Monkey who bashes the keyboard, the Boomer Mom, the Gen Z Kid, and the Alien Tech Machine.

His original creation was pure, fast, and super addictive. You can check the open source repository on GitHub.

Is There a Spacebar Clicker 2?

Many players search on Google for "Spacebar Clicker 2" hoping to find a sequel with world 2 or new mechanics. To be completely honest: Bruno Croci never made an official separate game called Spacebar Clicker 2.

Some unauthorized clone sites on the internet put "Spacebar Clicker 2" in their title just to show ads. However, in the player community, this 2026 updated edition on spacebarclicker.win is what many people call "version 2" because we fixed the old bugs from the original code and added genuine new tools like the 5-mode Spacebar Click Test and detailed Upgrades Guide.

Version History & Changelog

Here is the timeline of how Spacebar Clicker evolved from a 13kb contest game into a worldwide internet favorite:

  • Version 1.0 (2021) — The Original js13k Release: Built by Bruno Croci. Featured the core 10 upgrade tiers, procedural audio, falling spacebar rain effect, and local storage auto-saving.
  • Version 1.2 (2022–2024) — Viral Browser Hit: The game went viral across gaming portals like CrazyGames, IndieDB, and school unblocked game sites. Millions of players started competing for spacebar high scores.
  • Version 2.0 (2026) — The Modern Web Edition (This Site):
    • Fixed First-Click Glitch: In the original code, the first spacebar press on a fresh load was silently ignored. We fixed `canclick` so the first press registers immediately.
    • Fixed Invisible Particles: A missing CSS `#` hex color prefix (`483D21`) was fixed so floating point score particles show up clearly.
    • Interactive Spacebar CPS Test: We built the full Spacebar Click Test with 1s, 5s, 10s, 30s, and 60s modes, anti-cheat repeat blockers, rank badges, and local personal best records.
    • Strategy & Guides Hub: We wrote the full How to Play Guide and Upgrades Guide with exact cost scaling formulas.
    • Zero Trackers & Privacy: We keep the game 100% clean. No ads, no popups, no user tracking.

Why We Made These Guides and Tools

A lot of sites just copy the original game code, slap advertisements everywhere, and never improve anything. We did not want to do that. We love the minimalist spirit of Bruno Croci's game, so we kept the core game fast and zero-bloat. But we added what players were asking for: clear answers on what upgrades to buy first, a real tool to test finger speed, and transparent guides.
